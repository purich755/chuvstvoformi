# Чувство формы — демо главной страницы

Студия аппаратной коррекции фигуры и косметологии, Казань, ул. Юлиуса Фучика, 53.
Концепция «Одной линией»: тонкая сквозная линия в начале страницы волнистая и «потерянная», к финалу натягивается и дорисовывает силуэт из логотипа и подпись «Чувство формы».

## Запуск

```bash
npm install
npm run dev      # http://localhost:8530
npm run build && npm start   # прод на http://localhost:8531
```

Статический экспорт: `STATIC_EXPORT=true npx next build` → `out/`. GitHub Pages: `.github/workflows/pages.yml` (basePath = имя репозитория).

## Стек

Next.js 15 (App Router) + TypeScript · Tailwind CSS v4 (токены — CSS-переменные в `app/base.css`, стили секций в `app/sections.css`, слой `components`) · GSAP 3 + ScrollTrigger + Flip · Lenis (через `gsap.ticker`, `lenis.on('scroll', ScrollTrigger.update)`) · Framer Motion (панель карты тела, вкладки прайса, свайп-стопка записок) · next/font: Prata, Manrope, Marck Script, IBM Plex Mono (cyrillic + latin) · sharp.

## Скрипты данных

- `tools/dump-yandex.mjs` — карточка, галерея, отзывы, особенности, прайс из Яндекс Карт (Chrome, state-view + DOM) → `raw/`
- `scripts/fetch-images.mjs` — качает фото в максимальном размере (`orig`), режет кропы и пары «до/после» (sharp extract), делает WebP 1600/800, перекодирует видео, пишет manifest
- `scripts/trace-logo.mjs` — скелетизация и потрейс логотипа → SVG
- `scripts/build-map.mjs` — статичная схема района из тайлов OpenStreetMap
- `scripts/build-signature.mjs` — подпись из шрифта

## Отчёт

**Источники.** Яндекс Карты открылись в Chrome с первого раза: из state-view взяты прайс, особенности, остановки и метро, все 15 отзывов полным текстом (на Картах их 15 — две «страницы» по интерфейсу). VK и Telegram не использовались: VK — личная страница за логин-стеной, Telegram — закрытая ссылка-приглашение.

**Фото.** В галерее 24 фото и 3 видео. Скачаны все 24 в оригинальном размере и все 3 видео (HLS → mp4). На сайт пошли 13 кадров (+ 3 кропа с коллажа, 3 пары «до/после»), 2 видео — в лайтбокс:
`morpheus8-device` (первый экран), `morpheus8-face`, `lpg-master`, `lpg-handpiece`, `interior-hall`, `facade-entrance`, `facade-street`, `cavitation-leg`, `pads-belly`, `master-robe`, `wrap-belly`, `pressotherapy-suit`, `gloves-belly`, `ba-body-*`, `ba-hands-*`, `ba-face-*`, видео `wrap-candlelight`, `way-to-studio`.

**Что пришлось заменить и почему.**
- Логотип в карточке оказался хорошего качества (3157 px), но для анимации «одной линией» нужен контур, а не заливка: силуэт снят с логотипа скелетизацией в осевые линии, листья и заливка — потрейсом. Ручной перерисовки не понадобилось, форма совпадает с оригиналом.
- Все фото «до/после» с водяным знаком LOVOBEAUTY и вшитыми подписями. Пары разрезаны на половины, кадр обрезан мимо знака и надписей (отмечено `watermarkCropped` в manifest). На первых экранах их нет.
- Рекламные кадры производителей с моделями (EMS на мужском прессе, роликовая насадка, Morpheus8 на животе, флаер) не взяты. Для EMSLIM, сфер и RF‑лифтинга в ленте технологий — однотонные плашки с линейным паттерном.
- Видео с бинтовым обёртыванием не взято: текст на половину кадра. У видео при свечах обрезаны вшитая подпись и знак.
- Iframe Яндекс-виджета заменён своей схемой района (OSM): виджет показывает звёзды рейтинга и стороннюю рекламу. Клик открывает карточку на Картах, рядом — «Построить маршрут».
- H1 на телефоне меньше 56 px из брифа: слово «почувствовать» при 56 px не помещается в 320 px строки, кегль считается по ширине слова.
- Прелоадер укладывается в 1,45 с: прорисовка силуэта сокращена до 0,85–1,0 с, чтобы осталось время на сжатие в точку и её переезд к началу линии.
